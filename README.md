# MathOGE

MathOGE — браузерный конструктор тренировочных вариантов ОГЭ по математике. Проект работает как статическое клиентское приложение без серверной части: банк заданий, логика конструктора, предпросмотр, печать и локальное сохранение вариантов реализованы на HTML/CSS/JavaScript.

## Что работает сейчас

### Банк заданий

Банк построен в виде раскрывающейся структуры.

- Для практических заданий №1–5: **тип практического блока → комплект → пять связанных заданий**.
- Для обычных номеров: **номер ОГЭ → прототип → аналоги**.
- Можно добавить в вариант целиком комплект №1–5 или отдельное задание из обычного номера.
- Реальные разделы банка автоматически подгружаются после запуска страницы.
- Для ещё не заполненных номеров показывается пустая структура, а не скрытый раздел.

### Наполнение банка

На текущем этапе в приложении представлены:

- **№1–5 — практические задания**:
  - Маршруты;
  - Участки;
  - Квартиры;
  - Листы;
  - Печки;
  - Тарифы;
  - Шины.
- **№6 — дроби**: прототипы и аналоги.
- **№7 — координатная прямая**: прототипы ФИПИ и аналоги, в том числе сравнение выражений, дробей и квадратных корней.
- **№8 — степени и корни**: прототипы и аналоги; математические выражения приводятся к корректному отображению через MathJax/LaTeX и дополнительные форматтеры дробей.
- **№9 — уравнения**: 14 прототипов и 109 аналогов (123 задания) из предоставленного PDF банка ФИПИ, с ответами из его ключа и формулами LaTeX.
- **№10 — вероятности**: 18 прототипов и 198 аналогов (216 заданий), включая диаграммы Эйлера и деревья случайного опыта.
- **№11 — графики функций**: 10 прототипов и 91 аналог (101 задание).
- **№12 — расчёты по формулам**: 11 прототипов и 171 аналог (182 задания).
- **№13 — неравенства**: 10 прототипов и 119 аналогов (129 заданий), включая системы, выбор промежутка и задания с координатной прямой.
- **№14 — прогрессии**: 11 прототипов и 106 аналогов (117 заданий).
- **№15 — треугольники и их элементы**: 28 прототипов и 226 аналогов (254 задания), с переиспользуемыми геометрическими SVG-схемами.
- **№16–25** пока присутствуют как пустые разделы «Задания ещё не добавлены».

Данные практических блоков №1–5 хранят общее условие, связанные пять заданий, ответы и, где требуется, изображения/планы.

## Конструктор варианта

Вкладка **«Собрать вариант»** повторяет структуру банка и позволяет формировать текущий вариант непосредственно из раскрывающихся разделов.

Поддерживается:

- добавление и удаление отдельных заданий;
- добавление/удаление полного связанного комплекта №1–5;
- отображение количества заданий в текущем варианте;
- разделение счётчиков на часть 1 и часть 2;
- очистка текущего варианта;
- пользовательское название варианта;
- сохранение текущего состояния в браузере;
- переход в предпросмотр.

### Случайный вариант

На главной странице есть генератор случайного варианта. Он выбирает:

1. один полный комплект практических заданий №1–5;
2. по одному случайному заданию для каждого номера №6–25, который уже есть в банке.

Если некоторые номера ещё не наполнены, вариант всё равно создаётся, а интерфейс сообщает, каких номеров пока нет.

## Предпросмотр и печать

Вкладка **«Предпросмотр»** формирует ученическую версию варианта на основе текущей подборки.

Для практических заданий №1–5 сохраняются:

- общее условие комплекта;
- план/изображение, если он предусмотрен;
- правильный порядок пяти связанных заданий.

Доступны два режима печати:

- **«Печать с решением»** — печатная версия A4 с клетчатым местом для решения и отдельной страницей-ключом с ответами;
- **«Только задания · 2 на листе»** — компактная печать двух страниц заданий на одном листе A4 в альбомной ориентации, без ключа и полей решения.

Для печатной клетки используется SVG-разметка, чтобы сетка стабильно сохранялась при печати из браузера.

## Мои варианты и локальное хранение

MathOGE не использует сервер или базу данных. Текущий вариант и сохранённые варианты хранятся в `localStorage` браузера.

Это означает, что сохранения:

- доступны только в том же браузере/профиле;
- не синхронизируются между устройствами;
- могут исчезнуть после очистки данных сайта.

## Интерфейс

Приложение содержит следующие разделы:

- Главная;
- Банк заданий;
- Собрать вариант;
- Предпросмотр;
- Мои варианты.

Дополнительно пользователь может менять шрифт интерфейса. Формулы №8–10 отображаются с помощью MathJax 3, подключённого через CDN.

## Технологии

Проект не требует сборщика и package manager.

- HTML5;
- CSS3;
- vanilla JavaScript;
- `localStorage`;
- MathJax 3;
- SVG для части схем и печатной сетки.

Для локального запуска достаточно открыть `index.html` в браузере. Для полноценной работы динамически подключаемых файлов удобнее запускать проект через обычный локальный HTTP-сервер или GitHub Pages.

### Основные файлы

`index.html` — оболочка одностраничного интерфейса, навигация, секции приложения, подключение MathJax и стартовых JS-модулей.

`css/style.css` — основное оформление интерфейса, конструктора, карточек заданий, предпросмотра и адаптивной вёрстки.

`js/app.js` — базовая логика приложения и исходный массив заданий №6: навигация, текущий вариант, счётчики, сохранение, `localStorage`, базовый рендер и общие обработчики.

`js/bank-accordion.js` — раскрывающийся банк. Описывает семь типов практических заданий, работу с полными комплектами №1–5 и обычными прототипами/аналогами. Этот модуль последовательно загружает `routes-part-1.js` … `routes-part-6.js`.

`js/builder-accordion.js` — раскрывающийся банк внутри конструктора и генерация случайного варианта.

`js/preview-enhanced.js` — расширенный предпросмотр, группировка практического комплекта, планы, поля решения и страница с ключом.

`js/print-two-up.js` — дополнительная печать двух страниц заданий на одном листе и SVG-сетка для обычной печати.

### Данные практических заданий №1–5

`routes-part-1.js` … `routes-part-6.js` содержат банк комплектов «Маршруты». Изображения планов лежат в `assets/routes-data/`.

`plots-data.js` содержит комплекты «Участки», а `plots-format.js` добавляет ответы/изображения и одновременно выступает загрузчиком остальных дополнительных разделов банка.

`apartments-data.js`, `sheets-data.js`, `stoves-data.js`, `tariffs-data.js`, `tires-data.js` содержат соответствующие наборы практических заданий.

Файлы `*-format.js` дополняют данные ответами, планами/изображениями, форматированием таблиц и специальной логикой отображения/печати.

Изображения для «Участков» и «Квартир» находятся соответственно в `assets/plots-data/` и `assets/apartments-data/`.

### №7, №8 и №9

### Вспомогательные файлы

`empty-numbers.js` добавляет видимые пустые разделы №7–25 там, где реальных заданий ещё нет.

`fipi-answers.js`, `teacher-answers.js` содержат отдельные наборы ответов/ключей; часть актуальной логики ответов также находится непосредственно в форматтерах и `preview-enhanced.js`.

`empty-bank-structure.js`, `real-tasks.js`, `routes-plans.js` — вспомогательные/переходные файлы, оставшиеся в репозитории рядом с текущей модульной структурой. Основной стартовый путь приложения задаётся подключениями в `index.html` и динамическими загрузчиками в `bank-accordion.js` и `plots-format.js`.

## Как загружается приложение

Стартовые скрипты подключаются из `index.html` в таком порядке:

1. `app.js`;
2. `plots-data.js`;
3. `bank-accordion.js`;
4. `plots-format.js`;
5. `builder-accordion.js`;
6. `preview-enhanced.js`;
7. `print-two-up.js`.

После этого:

- `bank-accordion.js` загружает шесть частей банка «Маршруты»;
- `plots-format.js` динамически загружает «Квартиры», «Листы», «Печки», «Тарифы», «Шины», №7, №8, №9, №10, №11, №12, №13, №14, №15 и модуль пустых номеров;
- после загрузки банк и конструктор перерисовываются и обновляют счётчики.

## Текущее ограничение наполнения

MathOGE уже является рабочим конструктором, а не первоначальным демонстрационным прототипом, однако банк ещё не охватывает весь экзамен: на данный момент реальными заданиями наполнены №1–15, а №16–25 подготовлены в интерфейсе как пустые разделы для дальнейшего наполнения.

По мере добавления новых номеров генератор случайного варианта автоматически начнёт использовать их без изменения основной механики конструктора.
