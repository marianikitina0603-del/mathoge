# MathOGE

Прототип конструктора тренировочных вариантов ОГЭ по математике на основе структурированного банка заданий.

## Уже реализовано

- главная страница;
- банк заданий с фильтрами;
- ручное добавление заданий в вариант;
- генератор по номерам ОГЭ;
- текущий вариант;
- сохранение вариантов в `localStorage`;
- адаптивный интерфейс.

## Структура

- `index.html` — интерфейс приложения;
- `css/style.css` — стили;
- `js/app.js` — логика прототипа и временный демонстрационный банк.

## Следующие шаги

1. Вынести банк в `data/tasks.json`.
2. Добавить реальные тексты, ответы, изображения и связи прототипов/аналогов.
3. Особым типом данных хранить связанные практические задания №1–5.
4. Добавить просмотр готового варианта и печать.
5. Добавить режим ученика и автоматическую проверку.
6. Настроить GitHub Pages.
