# MathOGE

MathOGE — браузерный конструктор тренировочных вариантов ОГЭ по математике. Проект работает как статическое клиентское приложение без серверной части: банк заданий, конструктор, генераторы, предпросмотр, печать и локальное хранение реализованы на HTML/CSS/JavaScript.

Сайт: https://marianikitina0603-del.github.io/mathoge/

## Возможности

### Банк заданий

Банк построен в виде раскрывающейся структуры:

- для практических заданий №1–5: **тип практического блока → комплект → пять связанных заданий**;
- для №6–25: **номер ОГЭ → прототип → аналоги**;
- комплект №1–5 можно добавлять целиком;
- обычные задания можно добавлять по одному;
- тяжёлые разделы банка подгружаются динамически и рендерятся по мере открытия, чтобы уменьшить время загрузки страницы.

### Практические задания №1–5

В банке представлены связанные комплекты:

- Маршруты;
- Участки;
- Квартиры;
- Листы;
- Печки;
- Тарифы;
- Шины.

Каждый комплект хранит общее условие, пять связанных заданий, ответы и необходимые изображения/планы.

### Задания №6–25

В проекте используются реальные задания, прототипы и аналоги ОГЭ. Для математической записи применяется LaTeX/MathJax, а для графических задач — SVG и PNG-изображения.

Основные тематические разделы:

- №6 — вычисления;
- №7 — координатная прямая;
- №8 — степени и корни;
- №9 — уравнения;
- №10 — вероятность;
- №11 — графики функций;
- №12 — расчёты по формулам;
- №13 — неравенства;
- №14 — прогрессии;
- №15 — треугольники и их элементы;
- №16 — окружность, круг и их элементы;
- №17 — четырёхугольники;
- №18 — геометрия на клетчатой бумаге;
- №19 — теоретические утверждения по геометрии;
- №20 — уравнения и неравенства повышенного уровня;
- №21 — текстовые задачи;
- №22 — функции и графики;
- №23–25 — геометрические задачи второй части.

## Конструктор варианта

Вкладка **«Собрать вариант»** позволяет формировать собственный вариант из банка.

Поддерживается:

- добавление и удаление отдельных заданий;
- добавление и удаление полного комплекта №1–5;
- отдельные счётчики части 1 и части 2;
- пользовательское название варианта;
- очистка текущего варианта;
- сохранение текущего состояния в браузере;
- переход в предпросмотр и печать.

## Генераторы на главной странице

На главной странице доступны быстрые генераторы.

### Случайная часть 1 — №1–19

- №1–5 всегда выбираются **из одного связанного практического комплекта**;
- №6–19 выбираются случайно независимо — по одному реальному заданию каждого номера.

### Случайная часть 2 — №20–25

Создаётся случайный набор из шести заданий второй части — по одному заданию №20–25.

### Случайные задания №6–19

Формируется вариант только из основных непрактических заданий первой части.

### Пятиминутки

Есть отдельные генераторы по алгебре и геометрии. Пользователь может отметить номера, которые должны участвовать в генерации.

## Предпросмотр

Вкладка **«Предпросмотр»** формирует ученическую версию варианта.

Для №1–5 сохраняются:

- единое условие практического комплекта;
- план или изображение;
- правильный порядок связанных заданий.

В предпросмотре также формируется ключ с ID ФИПИ и ответами.

## Печать

Доступны два основных режима.

### Печать с решением

- формат A4;
- клетчатое поле для записи решения;
- для №20–25 каждое задание получает отдельную страницу с большим сплошным клетчатым полем;
- если печатается только часть 2, документ начинается сразу с №20 без отдельной пустой/титульной страницы;
- после заданий выводится отдельная страница-ключ;
- MathJax предварительно рендерится перед созданием печатной копии;
- текст и математические формулы приводятся к единому чёрному цвету при печати.

### Только задания · 2 на листе

- A4 в альбомной ориентации;
- две компактные страницы заданий на одном физическом листе;
- без клеток для решения и без ключа;
- изображения №15–18 автоматически уменьшаются и располагаются рядом с текстом;
- печатный документ создаётся в отдельном iframe, поэтому стили основного интерфейса не влияют на его разметку.

## Мои варианты и localStorage

MathOGE не использует сервер или базу данных. Текущий вариант и сохранённые варианты хранятся в `localStorage`.

Поэтому сохранения:

- доступны только в текущем браузере/профиле;
- не синхронизируются между устройствами;
- могут исчезнуть после очистки данных сайта.

## Производительность

Большой банк заданий загружается лениво.

- главный экран не строит сразу весь DOM банка;
- тяжёлые страницы банка и конструктора очищаются при переходах между разделами;
- банк и конструктор рендерят содержимое раскрываемых блоков по мере необходимости;
- дополнительные номера и изображения подключаются отдельными loader-скриптами.

Это особенно важно для №15–25, где используется большое количество аналогов и графических файлов.

## Интерфейс

Основные разделы приложения:

- Главная;
- Банк заданий;
- Собрать вариант;
- Предпросмотр;
- Мои варианты.

Пользователь может выбирать шрифт. Формулы отображаются через MathJax 3.

## Технологии

Проект не требует сборщика или package manager.

- HTML5;
- CSS3;
- vanilla JavaScript;
- `localStorage`;
- MathJax 3;
- SVG и PNG для схем и рисунков;
- GitHub Pages.

Для локальной разработки рекомендуется запускать проект через HTTP-сервер, поскольку значительная часть банка подключается динамически.

## Основные модули

`index.html` — оболочка одностраничного приложения и подключение стартовых модулей.

`js/app.js` — базовое состояние приложения, навигация, текущий вариант, счётчики и localStorage.

`js/bank-accordion.js` — раскрывающийся банк заданий.

`js/builder-accordion.js` — банк внутри конструктора.

`js/home-generators.js` — быстрые генераторы на главной странице, включая выбор единого комплекта №1–5 для случайной части 1.

`js/performance-loader.js` — ленивая загрузка большого банка и оптимизация переходов между тяжёлыми страницами.

`js/preview-enhanced.js` — формирование ученического предпросмотра и ключа.

`js/print-two-up.js` — режим «2 задания на листе», подготовка MathJax и общая печатная инфраструктура.

`js/ordinary-print-image-fix.js` — изолированная A4-печать с решением, размеры изображений, клетки №20–25 и печатный ключ.

`js/plots-format.js` — форматирование практических заданий «Участки» и основной динамический загрузчик дополнительных разделов банка.

`js/empty-numbers.js` — показывает заглушки только для действительно отсутствующих номеров и подключает дополнительные loader-модули.

## Принцип хранения задания

Обычное задание содержит как минимум номер ОГЭ, ID, текст и ответ. Прототипы и аналоги объединяются по номеру и идентификатору.

Практические задания №1–5 дополнительно содержат тип практического блока и номер комплекта. Именно эта связь используется при предпросмотре и генерации: пять заданий одного варианта должны относиться к одному комплекту.
